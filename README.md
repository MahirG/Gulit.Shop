# Gulit.Shop
A premium headless e-commerce marketplace for Ethiopia. Built with Next.js and Shopify, featuring Amharic localization and Chapa payment integration (Telebirr, CBEBirr) for a seamless local shopping experience. 
Gulit Mart 🇪🇹
The bridge between global technology and the Ethiopian market. This project focuses on high-performance retail, mobile-first design, and secure local financial integration.
Currency: ETB (Ethiopian Birr)
Payments: Chapa API (Telebirr, CBEBirr, Apollo, Bank of Abyssinia)
Frontend: Next.js + Tailwind CSS (Optimized for Ethiopic script)
Backend: Headless Shopify Storefront API
